# Account, cart and checkout routes are kept out of the index with
# <meta name="robots" content="noindex, follow"> — see PRIVATE_ROUTES in
# src/App.jsx — deliberately NOT with Disallow rules here.
#
# Disallow and noindex cancel each other out: a URL that crawlers may not fetch
# is a URL whose noindex they can never read, so anything already indexed (this
# site's sitemap used to list /login) would stay indexed indefinitely. Allowing
# the crawl is what gets these pages dropped.
#
# The previous rules were inert anyway — they were written as /cart/, /profile/,
# /orders/ with trailing slashes, while the routes are /cart, /profile, /orders.
